# 자동 시험

기능을 고칠 때 기존 기능이 깨지지 않았는지 확인하는 방법입니다. 세 가지가 있고, 앞의 둘은 자동으로 돌아갑니다.

| 시험 | 무엇을 확인하나 | 언제 돌아가나 | 어떻게 돌리나 |
| --- | --- | --- | --- |
| 자동 검사 | lint, 타입 검사, 단위 시험, 빌드 | PR을 올리거나 `main`에 병합할 때 | GitHub Actions `검사` (`.github/workflows/check.yml`) |
| 단위 시험 | 화면·DB 없이 맞고 틀림을 따질 수 있는 계산 | 자동 검사에 포함 | `npm test` |
| 핵심 흐름 DB 시험 | 관리자·멘토·멘티가 한 학기를 돌릴 때 되는 것과 막혀야 하는 것 35가지 | DB(마이그레이션)나 RLS를 고친 뒤 직접 | 아래 "DB 시험 돌리기" |

## 자동 검사가 실패했을 때

1. PR 화면 아래쪽 검사 목록에 빨간 X(**검사 / check**)가 뜹니다. 옆의 **Details**를 누릅니다.
2. 실행 결과 첫 화면(**Summary**)에 단계별 결과 표와, 실패한 단계의 **오류 로그 끝 60줄**이 한국어 제목과 함께 나옵니다.
3. lint·타입 오류와 실패한 시험은 PR의 **Files changed** 탭에서 문제가 된 줄에도 빨간 표시로 나옵니다.
4. 전체 로그가 필요하면 실행 화면 왼쪽의 **check** 작업 → 실패한 단계(빨간 X)를 펼칩니다.

한 단계가 실패해도 나머지 단계는 끝까지 돌아서, 문제를 한 번에 모두 볼 수 있습니다.

## 단위 시험 (`tests/unit/`)

| 파일 | 확인하는 것 |
| --- | --- |
| `login-key.test.ts` | 이름·소속으로 만든 가상 이메일이 DB `login_email()`과 같은지 (띄어쓰기, 대소문자, 전각·줄바꿈 공백, 풀어 쓴 한글), 이름·구분 문자·PIN 규칙 |
| `answer-length.test.ts` | 멘토 답변 글자 수가 DB `answer_length()`와 같은지 (공백 제외·포함, 이모지), 한국 시간 표시 |
| `backup-files.test.ts` | 백업 CSV: 엑셀 한글 깨짐 방지, 따옴표 처리, 엑셀 수식 실행 방지 |

앱과 DB가 같은 결과를 내야 하는 계산(가상 이메일, 답변 글자 수)은 운영 DB 함수가 실제로 낸 값을 기대값으로 적어 두었습니다. 한쪽만 고치면 시험이 깨집니다. 일부러 규칙을 바꿀 때는 DB 함수를 고친 뒤, 새 값을 DB에서 다시 받아 기대값을 고칩니다.

## DB 시험 돌리기 (`supabase/tests/core_loop.sql`)

1. Supabase 대시보드 → SQL Editor를 엽니다.
2. `supabase/tests/core_loop.sql` 내용을 모두 붙여 넣고 **Run**을 누릅니다.
3. 결과는 **오류 메시지 모양**으로 나옵니다. 끝에 일부러 오류를 내서 모든 변경을 되돌리기 때문입니다.
   - 첫 줄이 `통과 35 / 전체 35`면 정상입니다.
   - 실패가 있으면 "실패:" 아래에 단계 이름과 기대값·실제값이 나옵니다.

Claude Code에게 "DB 시험 돌려줘"라고 해도 됩니다 (Supabase 연결로 같은 파일을 실행).

시험 데이터는 모두 되돌려져 운영 DB에서 돌려도 남지 않습니다. 시험하는 동안 현재 학기가 잠깐 바뀌지만 이것도 되돌려집니다. 알림 요청도 되돌려져 실제 알림은 나가지 않습니다.

확인하는 단계: 가입(동의 기록, 동의 없는 가입·허가 없는 관리자 가입 거부) → 학기 지정 → 멘토 개설(스스로 공개 거부) → 멘티 질문(알림 요청) → 남의 톡방 차단 → 50자 답변 검증 → 안 읽은 수 → 강의 공개·수강·자료 접근 → 관리자 현황·열람 → 강사료(관리자만) → 학기 종료(읽기 전용) → 만족도(톡방 있던 멘티만, 결과는 관리자만) → 백업(관리자만) → 알림 구독(본인 것만).

## 하지 않는 것

- **화면 자동 시험(브라우저로 클릭)**: 실제 로그인에 CAPTCHA가 필요해서 자동으로 로그인할 수 없습니다. 화면을 크게 바꿀 때는 [architecture.md](architecture.md) 9.1의 기준으로 직접 확인합니다.
- **실제 알림 도착**: 휴대폰·PC의 브라우저 푸시 서비스가 필요해 직접 확인합니다 (6.9).
